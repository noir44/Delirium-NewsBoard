# Delirium News Board

Доска новостей в игре: вкладки, форматированный текст и картинки. Всё правится
файлами на сервере **во время работы** — без обновления мода, без других модов
и без Java-патчей (замена SSR Core + SSR Newsboard).

## Где лежат файлы

На сервере, в `Zomboid/Lua/DelNews/` (при первом запуске мод создаёт папку,
`config.ini` и пример `news.txt`):

| файл | что это |
|---|---|
| `news.txt` | новости по умолчанию |
| `news_RU.txt`, `news_UA.txt`, `news_EN.txt`, ... | версия для игроков с этим языком игры (необязательно) |
| `*.png` | картинки, на которые ссылается текст |
| `config.ini` | настройки |

Файлы перечитываются раз в `pollSeconds` секунд. Изменился текст — у игроков
мигает кнопка «Новости» и всплывает «Новости обновлены»; открытое окно
обновляется само.

## Формат новостей

Тот же, что у SSR Newsboard, старые файлы можно копировать как есть:

```
Заголовок первой вкладки
<H1> Большой заголовок
<SIZE:medium> Обычный текст. <RGB:1,0.5,0.5> Красноватый. <RGB:1,1,1> Снова белый.
<CENTRE> <IMG:map_2026.png>
<LEFT> Текст под картинкой.
<PAGE>
Заголовок второй вкладки
...
```

- Строка `<PAGE>` — конец вкладки; следующая строка — заголовок новой.
- Строка `<VERSION: ...>` в начале файла не нужна (если есть — игнорируется):
  изменения ловятся по содержимому.
- Ванильные теги `ISRichTextPanel`: `<H1>`, `<H2>`, `<SIZE:small|medium|large>`,
  `<RGB:r,g,b>`, `<PUSHRGB:r,g,b>`/`<POPRGB>`, `<CENTRE>`, `<LEFT>`, `<RIGHT>`,
  `<SPACE>`, `<BR>`, `<LINE>`.
- Свои: `<IMG:файл.png>` — картинка из `Zomboid/Lua/DelNews/` (центрируется,
  уменьшается под ширину окна); `<HEX:ff8800>` — цвет; `<LINK:текст>` —
  подсвеченный текст (не кликается).
- Сохранять в UTF-8 (с BOM или без).

## Картинки

- Положить PNG в `Zomboid/Lua/DelNews/` и вставить `<IMG:имя.png>` в текст.
- Имя — **латиница, цифры, `_`, `-`, `.`**, без пробелов и папок.
- Сервер сам режет картинку на куски и отдаёт игрокам; у игрока она кэшируется
  в `Zomboid/Lua/DelNews_cache/` и второй раз не качается.
- Замена картинки: проще всего новое имя файла. Если оставить старое, замену
  поймают по изменившемуся размеру файла.
- Размер: 0.6 МБ — нормально (≈50 кусков по 16 КБ, при `imageChunksPerTick=2`
  несколько секунд). Чем меньше файл, тем быстрее у игроков.

## config.ini

| ключ | по умолчанию | смысл |
|---|---|---|
| `showOnLogin` | `new` | `new` — открыть при входе, если новости изменились с прошлого прочтения; `always` — при каждом входе; `never` — только мигает кнопка |
| `pollSeconds` | `10` | как часто перечитывать файлы (реальные секунды, минимум 2) |
| `imageChunksPerTick` | `2` | скорость раздачи картинок (кусков по ~16 КБ за тик сервера, 1–20) |

`config.ini` читается при старте сервера.

## Картинки: какой путь писать

Файл лежит на сервере в `Zomboid/Lua/DelNews/` (`C:\Users\admin\Zomboid\Lua\DelNews\n99.png`),
в тексте пишется **только имя файла**:

```
<IMG:n99.png>
<IMG:n99.png,800,450>      (необязательно: свой размер; шире окна всё равно ужмётся)
```

Старые теги SSR тоже работают: `<IMAGECENTRE:media/ui/n99.png>` сначала ищет
картинку в файлах модов (например `n1.png` из `media/ui/` этого мода), а если её там
нет — берёт файл с тем же именем (`n99.png`) из папки сервера. Картинки нет
нигде — вместо неё строка «картинка не найдена», остальное окно работает.
Новая картинка в папке подхватывается без правки `news.txt`.

## Картинки внутри мода

В `42/media/ui/` лежат картинки, перенесённые из старого мода `delnews`
(`n1`–`n4`, `nn1`–`nn6`) — по тому же пути, поэтому старые теги
`<IMAGECENTRE:media/ui/n1.png>` работают без правки. Такие картинки игроки
получают один раз вместе с модом через Steam; новая картинка этим путём
требует обновления мода, для живой замены — папка сервера и `<IMG:...>`.
